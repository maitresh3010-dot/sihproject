# dataset/ocr

Cached OCR / text-extraction outputs (JSON or TXT), one per source file.

Format for image OCR caches (`<image-stem>.json`):

```json
{
  "source": "abc-biscuits-front.jpg",
  "text": "...raw OCR text...",
  "confidence": 0.94,
  "engine": "tesseract"
}
```

`legal_metrology.txt` (generated by `dataset/extract_pdf.py`) holds the
reference PDF text used when curating `legalMetrologyRules.json`.
